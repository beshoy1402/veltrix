# VELTRIX — Digital Innovation Studio

Next.js + React + TypeScript agency website.

## Local development
1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` when Supabase integration is ready.
4. Run `npm run dev` and open http://localhost:3000.

## Deployment
Import this repository into Vercel and select the Next.js framework preset. Configure the Supabase public URL and publishable key in Vercel project environment variables before enabling database-backed features.

## Current release
- Responsive editorial agency homepage.
- English / Arabic language toggle with RTL layout foundation.
- Services catalogue with EGP 20,000 minimum project pricing.
- Concept portfolio with project preview modal.
- Agency story, process, insights teaser and contact CTA.
- Responsive navigation and reduced-motion support.

Portfolio cards are clearly labelled as illustrative concepts. They are not represented as completed client projects. Inquiry submission, real iframe previews, admin CMS, booking, newsletter, analytics and client portal are subsequent integration milestones.

Never commit service-role keys or other private credentials.
